  <h2 id="engagements">Working With Us</h2>
  <p>We take on a small number of engagements at a time so each one gets real attention. Most start with a conversation about the problem, followed by a short scoping phase where we map the work before committing to it.</p>
  <p>We are a good fit if you need a system built properly and maintained over time. We are a poor fit if you need a demo by Friday.</p>
